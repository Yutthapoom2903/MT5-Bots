# MT5-Bots

บอทเทรด XAUUSD (ทองคำ) บน MetaTrader 5 — MA20/MA50 crossover บน M15 เป็นจุดชนวน
H1 กำหนดทิศ M5 ยืนยัน ADX/RSI/spread ยับยั้ง บันทึกทุกแท่งพร้อมเหตุผลที่ตัดสินแบบนั้น

**ทุกอย่างสั่งผ่าน `run.py` คำสั่งเดียว**

---

## รอบการใช้งานประจำวัน

### ที่บ้าน (Windows + MT5 เปิดอยู่) — ปล่อยรันข้ามคืน

```powershell
python run.py
```

จบในคำสั่งเดียว: หา Symbol → ตรวจความพร้อม → วัดตัวกรองจากข้อมูลที่เก็บมา →
จำลองย้อนหลัง → กวาดค่า → เฝ้าดูตลาดสด **โหมดนี้ไม่ส่งคำสั่งซื้อขาย**

เช้ามากด `Ctrl+C` แล้ว push ข้อมูลขึ้น git — CSV ติดตาม git อยู่ ไม่ push ข้อมูลไม่ไปไหน

```powershell
git add *.csv && git commit -m "add data" && git push
```

### ที่ทำงาน (WSL ไม่มี MT5) — อ่านผล

```bash
git pull

.venv/bin/python run.py report     # บอทรันครบไหม + รายวัน + ระยะห่างจากเกณฑ์
.venv/bin/python run.py outcomes   # ตัวกรองแยกแท่งที่เทรนด์ไปต่อได้จริงไหม
```

> `bot.log` อยู่ใน `.gitignore` ส่วน "ปัญหาใน bot.log" ของ report จึงว่างเสมอที่ทำงาน
> อยากอ่าน error ต้องดูที่เครื่องบ้าน

### สิ่งที่ทำให้ข้อมูลเสียหายที่สุด: ปล่อยให้บอทดับกลางคัน

`outcomes` ติดป้ายให้แท่งได้ก็ต่อเมื่อแท่งถัดไปต่อเนื่องกันจริง ช่องที่ขาดกินป้ายมากกว่าที่คิด —
คืนแรกขาดไป 96 แท่ง เหลือป้ายแค่ 14 จาก 39 แท่ง ทั้งที่ควรได้ราว 31

`run.py report` หัวข้อ **ความต่อเนื่อง** บอกว่าขาดตรงไหนบ้าง ดูอันนี้ก่อนเชื่อสถิติอื่น

| `python run.py symbols` | หาชื่อ Symbol จริงของ broker | ใช่ |
| `python run.py signal` | คำตัดสินตอนนี้ครั้งเดียว พร้อมเหตุผลทุกข้อ | ใช่ |
| `python run.py watch` | เฝ้าดูและบันทึกต่อเนื่อง ไม่ส่งคำสั่ง | ใช่ |
| `python run.py trade` | เฝ้าดูและส่งคำสั่งจริง | ใช่ |
| `python run.py backtest` | จำลองกลยุทธ์ย้อนหลังบนข้อมูลจริง | ใช่ |
| `python run.py sweep` | กวาดหลายชุดค่า ดูว่าผลทนหรือแค่ฟลุค | ใช่ |
| `python run.py report` | **สรุปว่าบอททำอะไรไปบ้าง** | ไม่ |
| `python run.py outcomes` | **วัดว่าตัวกรองแยกอะไรได้จริงไหม** | ไม่ |

## เรื่องทุน — อ่านก่อนใช้เงินจริง

XAUUSD ไม้เล็กสุดคือ **0.01 lot** เล็กกว่านี้ไม่ได้ SL ของบอทคือ `ATR × 1.5` ราว **$16 ต่อไม้**
แปลว่าไม้ที่เล็กที่สุดที่เปิดได้ก็เสี่ยง $16 แล้ว กดต่ำกว่านี้ไม่ได้

| ทุน | เสี่ยงต่อไม้ | สภาพ |
|---|---|---|
| $500 | 3.3% | อันตราย |
| $1,000 | 1.6% | ตึง |
| **$2,000** | **0.8%** | **แนะนำอย่างต่ำ** |
| $3,300 | 0.5% | สบาย |

Demo เสี่ยงเกินงบแล้วเทรดต่อพร้อมเตือนใน log **บัญชีจริงปฏิเสธไม่เข้าไม้**
`python run.py check` คำนวณเลขนี้กับบัญชีจริงให้ดู เป็นทางที่เร็วที่สุดในการตอบว่า
"ทำไมบอทไม่เข้าไม้สักที"

ค่าที่แก้ได้ใน `runner.py`: `RISK_PERCENT` (1.0), `SL_ATR_MULT` (1.5), `TP_ATR_MULT` (3.0),
`MAX_DAILY_LOSS_PERCENT` (3.0), `MAX_TRADES_PER_DAY` (5), `MAX_CONSECUTIVE_LOSSES` (3)

## บอทตัดสินใจยังไง

| Timeframe | หน้าที่ |
|---|---|
| H1 | กำหนดทิศ — เทรดตามเทรนด์ใหญ่เท่านั้น |
| M15 | จุดชนวน — MA20 ตัด MA50 |
| M5 | ยืนยัน — โมเมนตัมสั้นต้องไม่สวน |
| ADX / RSI / spread | ยับยั้ง — ตลาดไม่มีเทรนด์ หรือราคายืดไปแล้ว ให้ข้าม |

ใช้เฉพาะ**แท่งที่ปิดแล้ว** เข้าช้ากว่าราคาปัจจุบันเสมอ — ตั้งใจ ไม่งั้นสัญญาณพลิกกลางแท่ง

ตัวกรองเปิด/ปิดได้ทีละตัวใน `strategy.py` (`USE_H1_TREND_FILTER`, `USE_ADX_FILTER`,
`USE_RSI_FILTER`, `USE_M5_CONFIRM`) พร้อมเกณฑ์ `ADX_MIN` (20), `MAX_SPREAD_POINTS` (50)

หลังเปิดไม้: เลื่อน SL ไป breakeven ที่ 1R แล้วไล่ตาม ATR ที่ 1.5R
**SL ขยับไปทางกำไรอย่างเดียว ไม่มีทางถอยกลับ**

## Telegram (ไม่ใส่ก็ได้ บอททำงานปกติ)

สร้าง `.env` (คัดจาก `.env.example`)

```
TELEGRAM_TOKEN=โทเคนจาก @BotFather
TELEGRAM_CHAT_ID=chat id ของคุณ
```

```powershell
python run.py notify --dry    # พิมพ์ตัวอย่างลงจอ ไม่ต้องมี token
python run.py notify --check  # ข้อความไม่มา ใช้อันนี้หาว่าขาดตรงไหน
```

- **บอทเริ่มบทสนทนาเองไม่ได้** ต้องกด Start ในแชทบอทก่อนหนึ่งครั้ง ไม่งั้น Telegram ตอบ 403 ตลอด
- **กรอกลง `.env` เท่านั้น** `.env.example` เป็นแบบฟอร์ม โปรแกรมไม่อ่าน และไฟล์นั้นติดตาม git อยู่ —
  กรอก token ลงไปคือเตรียม commit ความลับขึ้น repo (`--check` ดักให้แล้ว)

8 หมวด เปิด/ปิดแยกกันได้ใน `notify.py`: `lifecycle` `market` `signal` `entry` `manage`
`exit` `risk` `summary` — `SEND_HOLD` เปิดมาโดยตั้งใจ ข้อความทุกแท่งคือหลักฐานถูกที่สุดว่าท่อไม่ตัน
เชื่อใจแล้วค่อยปิด

## ข้อควรรู้

- **ยังไม่เคยทดสอบกับ MT5 จริง** logic ผ่านเทสหมด แต่พฤติกรรม broker (retcode,
  ระยะ stop ขั้นต่ำ, filling mode) ต้องเจอของจริงถึงรู้ — **Demo ก่อน**
- MA crossover เป็นกลยุทธ์ตามเทรนด์ ตลาด sideway จะแพ้เป็นชุด ADX ช่วยได้ระดับหนึ่ง ไม่ได้แก้หมด
- ตัวเลขจาก `outcomes` เป็นการเคลื่อนไหวของตลาดดิบๆ **ไม่ใช่กำไรของไม้** ไม่มี spread
  ไม่มีเลื่อน stop ไม่มี TP — จะตัดสินว่ากลยุทธ์ทำเงินได้ไหมต้องใช้ `run.py backtest`
- ผล Demo ไม่เท่าผลจริง ไม่มี slippage และ requote แบบบัญชีจริง
- รองรับ symbol เดียวเท่านั้น — ทุก risk limit, ตัวตัดวงจร และ state file ออกแบบมาแบบนั้น
