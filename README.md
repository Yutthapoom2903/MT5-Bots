# MT5-Bots

บอทเทรด XAUUSD (ทองคำ) บน MetaTrader 5 ใช้ MA20/MA50 crossover เป็นจุดชนวน
แล้วกรองด้วยหลาย timeframe ก่อนตัดสินใจเอง

**ทุกอย่างสั่งผ่านคำสั่งเดียว: `python run.py`**

---

## สิ่งที่ต้องมีก่อน

1. **Windows** — แพ็กเกจ `MetaTrader5` ของ Python ทำงานบน Windows เท่านั้น
   รันจาก WSL หรือ Linux ไม่ได้ (ยกเว้นคำสั่ง `backtest` กับ `test`)
2. **MT5 terminal เปิดอยู่และล็อกอินแล้ว** บอทคุยกับ terminal ที่เปิดอยู่ ไม่ได้ล็อกอินเอง
3. **เปิด Algo Trading ใน MT5** ปุ่มบนแถบเครื่องมือ ถ้าไม่เปิดคำสั่งจะถูกปฏิเสธ
4. Python 3.9 ขึ้นไป

## ติดตั้ง

```powershell
pip install -r requirements.txt
```

บน WSL/Linux ติดตั้งแบบนี้ไม่ได้เพราะ `MetaTrader5` มีแต่ตัว Windows — ถ้าอยากรันเทส
จากฝั่ง Linux ให้ลงเฉพาะที่เหลือใน venv (`.venv/` อยู่ใน `.gitignore` แล้ว)

```bash
python3 -m venv .venv && .venv/bin/pip install pandas requests python-dotenv
.venv/bin/python run.py test
```

สร้างไฟล์ `.env` (คัดลอกจาก `.env.example`) ถ้าต้องการแจ้งเตือนผ่าน Telegram —
ไม่ใส่ก็ได้ บอททำงานปกติ แค่ไม่ส่งข้อความ

```
TELEGRAM_TOKEN=โทเคนจาก @BotFather
TELEGRAM_CHAT_ID=chat id ของคุณ
```

ตั้งเสร็จลองยิงตัวอย่างครบทุกหมวดเข้าห้องแชทตัวเองก่อนได้

```powershell
python run.py notify          # ส่งจริง
python run.py notify --dry    # แค่พิมพ์ลงจอ ไม่ต้องมี token
python run.py notify --check  # ข้อความไม่มา ใช้อันนี้หาว่าขาดตรงไหน
```

`--check` ไล่ตรวจให้ทีละข้อ: หาไฟล์ `.env` เจอไหม, รูปแบบ token ถูกไหม, `getMe` ผ่านไหม,
`chat_id` ตรงกับแชทที่เคยทักบอทไหม แล้วยิงข้อความทดสอบจริงหนึ่งข้อความ

**บอทเริ่มบทสนทนาเองไม่ได้** — ต้องเปิดแชทบอทใน Telegram แล้วกด Start หรือพิมพ์อะไรก็ได้
หนึ่งครั้งก่อน ไม่งั้น Telegram ตอบ 403 ตลอดไม่ว่า token จะถูกแค่ไหน

**กรอกค่าลง `.env` เท่านั้น** — `.env.example` เป็นแค่แบบฟอร์ม โปรแกรมไม่อ่าน และไฟล์นั้น
ติดตาม git อยู่ กรอก token ลงไปคือเตรียม commit ความลับขึ้น repo `--check` ดักให้แล้ว

## อ่านผลจำลองย้อนหลังยังไง

ขั้น 3 เทียบให้ว่า**ตัวกรองช่วยจริงหรือแค่ทำให้เทรดน้อยลง**

```
--- crossover เปล่าๆ ไม่มีตัวกรอง ---
จำนวนไม้: 279  (ชนะ 107 แพ้ 172)
คาดหวังต่อไม้: -0.172R
Drawdown สูงสุด: -47.96R

--- ใส่ตัวกรองหลาย timeframe ---
จำนวนไม้: 78  (ชนะ 38 แพ้ 40)
คาดหวังต่อไม้: +0.028R
Drawdown สูงสุด: -6.41R
```

วัดเป็น **R** = หน่วยความเสี่ยงต่อไม้ ไม่ใช่เงิน `+1R` คือกำไรเท่ากับที่เสี่ยงไป
ใช้ R เพราะไม่ขึ้นกับขนาดพอร์ตหรือ lot จึงเทียบข้ามช่วงเวลาและข้ามการตั้งค่าได้ตรงๆ

**ตัวเลขที่ต้องดู** ไม่ใช่ win rate แต่คือ **คาดหวังต่อไม้ (expectancy)** ติดลบเมื่อไหร่
แปลว่ายิ่งเทรดยิ่งเสีย ต่อให้ win rate 60% ก็ตาม และ **drawdown สูงสุด** บอกว่าต้อง
ทนเห็นพอร์ตติดลบแค่ไหนก่อนจะกลับมา

ขั้น 4 ดูว่าผล **ทน** ไหม

- บวกเป็นย่านกว้าง → น่าจะมีขอบจริง เลือกค่ากลางย่าน
- บวกแค่ชุดเดียว ข้างเคียงติดลบหมด → ฟลุค อย่าเอาไปใช้
- ไม่บวกสักชุด → กลยุทธ์นี้ยังไม่มีขอบในช่วงนี้ อย่าเทรดเงินจริง

### ข้อจำกัดที่ต้องรู้ก่อนเชื่อผล

- ไม่รู้ลำดับราคาในแท่ง ถ้าแท่งเดียวชนทั้ง SL และ TP นับว่า **SL ชนก่อนเสมอ**
  เป็นสมมติฐานฝั่งแย่ ผลจริงจึงมักดีกว่าที่จำลองนิดหน่อย
- ไล่ stop จำลองที่ราคาปิดแต่ละแท่ง M15 แต่บอทจริงขยับทุก 30 วินาที
- spread ใช้ค่าคงที่ (`--spread` ปรับได้) ของจริงกว้างขึ้นตอนข่าว
- ไม่มี slippage ไม่มี requote
- **ผลดีในอดีตไม่ได้แปลว่าจะดีในอนาคต** ยิ่งจูนค่าจนสวยยิ่งเสี่ยง overfit

## บอทตัดสินใจยังไง

ไม่ได้ดู timeframe เดียว แต่ละอันมีหน้าที่ต่างกัน:

| Timeframe | หน้าที่ |
|---|---|
| **H1** | กำหนดทิศ — เทรดตามเทรนด์ใหญ่เท่านั้น ไม่สวน |
| **M15** | จุดชนวน — MA20 ตัด MA50 คือจังหวะเข้า |
| **M5** | ยืนยัน — โมเมนตัมสั้นต้องไม่สวนกับไม้ที่จะเปิด |

แล้วกรองอีกชั้นก่อนเข้าจริง:

| ตัวกรอง | เหตุผล |
|---|---|
| ADX ≥ 20 | ตลาด sideway คือที่ที่ MA crossover ให้สัญญาณหลอกถี่สุด |
| RSI 30–70 | ไม่ไล่ราคาที่ยืดไปไกลแล้ว |
| spread ≤ 50 points | spread กว้างกินกำไรตั้งแต่ยังไม่เริ่ม |
| ช่วงเวลา | ปิดไว้เป็นค่าเริ่มต้น เปิดได้ใน `strategy.py` |

**ถ้าจะเปิดตัวกรองช่วงเวลา** ต้องรู้ก่อนว่า broker คุณใช้เวลาอะไร — `run.py check` บอก
GMT offset ให้ (ส่วนใหญ่ GMT+2/+3 และขยับตาม DST) `SESSION_HOURS` เป็น**เวลาเซิร์ฟเวอร์**
ไม่ใช่เวลาไทย ตั้งผิดแล้วบอทจะไม่เทรดเลยหรือเทรดผิดช่วง

ทุกตัวเปิด/ปิดแยกกันได้ที่หัวไฟล์ `strategy.py` — **ปิดทีละตัวแล้ววัดผล**
อย่าเปลี่ยนพร้อมกันหลายอย่าง จะไม่รู้ว่าตัวไหนช่วยตัวไหนทำพัง

## บอทดูแลไม้ยังไงหลังเปิดแล้ว

เปิดไม้แล้วไม่ได้ทิ้ง — ทุกรอบ 30 วินาที (ไม่ใช่แค่ตอนแท่งปิด) บอทจะดู SL ให้

| กลไก | ทำงานเมื่อ | ทำอะไร |
|---|---|---|
| **เก็บกำไรครึ่งไม้** | กำไรถึง 1R | ปิด 50% ปล่อยที่เหลือวิ่งต่อ |
| **ย้ายมาเสมอทุน** | กำไรถึง 1R | เลื่อน SL มาที่ราคาเข้า +0.1R กันค่า spread |
| **ไล่ stop** | กำไรถึง 1.5R | ลาก SL ตามห่างจากราคา 2×ATR |

`1R` = ระยะ SL ตอนเปิดไม้ ถ้าเสี่ยง $16 แล้วกำไรถึง $16 คือ 1R

**SL ขยับไปทางกำไรได้อย่างเดียว ถอยหลังไม่ได้เด็ดขาด** ถ้าถอยได้เมื่อไหร่ การไล่ stop
จะกลายเป็นการขยายความเสี่ยงแทน

**พอร์ตเล็กแบ่งปิดไม่ได้** — 0.01 lot คือขั้นต่ำ แบ่งครึ่งแล้วเหลือ 0.005 ซึ่ง broker
ไม่รับ บอทจะข้ามการเก็บกำไรบางส่วนแล้วบอกใน log ครั้งเดียว ปล่อยเต็มไม้ต่อ
จะใช้ฟีเจอร์นี้ได้ต้องเปิดอย่างน้อย 0.02 lot

ปิด/ปรับได้ที่ `USE_PARTIAL_TP`, `USE_BREAKEVEN`, `USE_TRAILING`, `BREAKEVEN_AT_R`,
`TRAIL_START_R`, `TRAIL_ATR_MULT` ใน `runner.py`

## ตัวตัดวงจร — บอทหยุดเองเมื่อวันไม่เข้าทาง

รันทิ้งไว้ที่บ้านโดยไม่มีคนเฝ้า สิ่งที่กลัวที่สุดคือวันที่บอทแพ้รัวแล้วไม่มีใครปิด

| เพดาน | ค่าเริ่มต้น | ผล |
|---|---|---|
| ขาดทุนต่อวัน | 3% ของทุนต้นวัน | หยุดเข้าไม้ใหม่ทั้งวัน |
| จำนวนไม้ต่อวัน | 5 ไม้ | หยุดเข้าไม้ใหม่ทั้งวัน |
| แพ้ติดกัน | 3 ไม้ | หยุดเข้าไม้ใหม่ทั้งวัน |

หยุดแค่**การเข้าไม้ใหม่** ไม้ที่ถืออยู่ยังถูกดูแล SL ต่อตามปกติ

ตัวเลขอ่านจากประวัติจริงใน MT5 ทุกครั้ง ไม่ได้นับในหน่วยความจำ — restart บอทกลางวัน
เพดานก็ยังนับต่อถูก ไม่รีเซ็ต

พอขึ้นวันใหม่ บอทรีเซ็ตเพดานและส่งสรุปของเมื่อวานเข้า Telegram

แก้ที่ `MAX_DAILY_LOSS_PERCENT`, `MAX_TRADES_PER_DAY`, `MAX_CONSECUTIVE_LOSSES`

## ความทนทานเวลารันทิ้งไว้

- **หลุดการเชื่อมต่อ** — ถ้า MT5 terminal ปิดหรือเน็ตหลุด บอทตรวจเจอแล้วเชื่อมใหม่เอง
  ไม่ตายเงียบ
- **ตลาดปิด** — เสาร์อาทิตย์บอทไม่ poll ถี่ ถอยไปเช็คทุก 5 นาทีแทน
- **restart กลางแท่ง** — `bot_state.json` จำแท่งล่าสุดที่ประมวลผลแล้ว ไม่ยิงซ้ำ
- **restart ระหว่างถือไม้** — จำ 1R ของแต่ละ ticket ไว้ ถ้าหาย ประมาณจาก SL ปัจจุบันแทน
- **error ที่ไม่คาดคิด** — เขียน traceback ลง `bot.log` แล้วแจ้ง Telegram ก่อนหยุด
- **heartbeat** — ทุก 12 ชั่วโมงส่ง Telegram บอก equity ไม้ที่ถืออยู่ และแท่งล่าสุด
  จะได้รู้ทันทีถ้าบอทตายเงียบ ปิดได้ด้วย `HEARTBEAT_EVERY_HOURS = 0`

## แจ้งเตือน Telegram

ทุกข้อความติดไอคอนหมวดไว้ที่หัวเรื่อง กวาดตาในห้องแชทแล้วรู้ทันทีว่าเรื่องอะไร
เปิด/ปิดได้ทีละหมวดที่สวิตช์ `SEND_*` บนหัวไฟล์ `notify.py`

| หมวด | ส่งเมื่อไร | เสียง |
|---|---|---|
| 🤖 ระบบ | บอทเริ่ม/หยุด/พัง, MT5 หลุดและต่อกลับได้ | ดัง |
| 🕒 ตลาด | ตลาดปิด (เสาร์อาทิตย์) และตลาดกลับมาเปิด | เงียบ/ดัง |
| 📊 สัญญาณ | คำตัดสินรายแท่ง พร้อมตัวกรองครบทุกข้อ | ตามผล |
| 🚀 เข้าไม้ | ส่งคำสั่งสำเร็จ พร้อม SL/TP/R:R และเงินที่เสี่ยง — หรือไม่สำเร็จพร้อม retcode | ดัง |
| 🛡️ ดูแลไม้ | ขยับ SL (เสมอทุน/ไล่ตาม), เก็บกำไรบางส่วน | เงียบ |
| 🏁 ปิดไม้ | ไม้ปิดแล้ว พร้อมกำไรสุทธิและ R ที่ได้จริง | ดัง |
| ⚠️ ความเสี่ยง | ไม้ขั้นต่ำเกินงบ, ตัวตัดวงจรหยุดเข้าไม้ และตอนกลับมาเข้าได้ | ดัง |
| 📅 สรุป | สรุปรายวันตอนตัดวัน, heartbeat | เงียบ |

ลูกเล่นในข้อความ: แถบวัด RSI/ADX/ATR/spread ให้เห็นตำแหน่งของค่าในช่วงโดยไม่ต้องคิด,
✅/❌ ต่อตัวกรองพร้อมตัวเลขที่ใช้ตัดสิน, 🟩🟩 แทนขนาดกำไรเป็น R, แถบอัตราชนะในสรุปรายวัน

หมวดสัญญาณละเอียดกว่าหมวดอื่นเพราะความถี่ต่างกันมาก

- `SEND_NEAR_MISS = True` — มีสัญญาณตัดกันแต่ติดตัวกรอง บอกว่าติดข้อไหน (เปิดไว้)
- `SEND_HOLD = True` — ทุกแท่งที่ยังไม่มีสัญญาณ ได้ข้อความทุก 15 นาที (เปิดไว้ให้)
  ส่งแบบเงียบไม่มีเสียง ใช้ยืนยันว่าบอทยังหายใจและท่อไม่ตัน เชื่อใจแล้วปิดได้

**กันสแปมสองชั้น** — ข้อความเนื้อเดียวกันซ้ำภายใน 15 นาทีถูกตัดทิ้ง และบางหมวดมีคูลดาวน์
ของตัวเอง เช่นตลาดปิดแจ้งได้ไม่เกินทุก 6 ชั่วโมง ไม่งั้นสุดสัปดาห์เดียวได้เป็นร้อยข้อความ

ส่งไม่ได้ก็ไม่ทำให้บอทหยุด — เขียนเตือนลง `bot.log` แล้วไปต่อ

## เรื่องทุน — อ่านให้จบก่อนใช้เงินจริง

XAUUSD ไม้เล็กสุดคือ **0.01 lot = ทอง 1 ออนซ์** เล็กกว่านี้ไม่ได้

SL ของบอทคือ `ATR × 1.5` ซึ่งตอนนี้อยู่ราว **$16 ต่อไม้** แปลว่าไม้ที่เล็กที่สุด
ที่เปิดได้ก็เสี่ยง $16 แล้ว กดต่ำกว่านี้ไม่ได้

| ทุน | เสี่ยงต่อไม้ | สภาพ |
|---|---|---|
| $500 | 3.3% | อันตราย แพ้ 10 ไม้ = พอร์ตหาย 1 ใน 3 |
| **$1,000** | **1.6%** | ตึง แต่พอไปได้ |
| $2,000 | 0.8% | เหมาะสม |
| $3,300 | 0.5% | ตรงตามค่าเริ่มต้นเดิม |

**แนะนำอย่างต่ำ $2,000** ถ้าจะใช้เงินจริง

ค่าเริ่มต้นคือ `RISK_PERCENT = 1.0` ใน `runner.py`

**บน Demo บอทจะเทรดต่อโดยเตือนใน log** ว่าเสี่ยงเกินงบไปเท่าไร เพราะจุดประสงค์ของ Demo
คือได้เห็นบอททำงานจริง **บนบัญชีจริงบอทจะปฏิเสธไม่เข้าไม้** แล้วบอกเหตุผล ทางเลือกคือ

- เพิ่มทุนเป็น $1,700 ขึ้นไป (ทางที่ถูกต้อง)
- ตั้ง `RISK_PERCENT = 2.0` — ยอมรับว่าเสี่ยงสูงขึ้น
- ลด `SL_ATR_MULT` — แต่ SL แคบลงแปลว่าโดน stop ง่ายขึ้น ระวัง
- ตั้ง `ALLOW_RISK_OVER_BUDGET = True` — ให้เทรดทั้งที่รู้ว่าเกินงบ

บน Demo จะเลือกอะไรก็ได้ ไม่มีอะไรเสียหาย แต่พอขึ้นเงินจริงต้องคิดให้จบ

| ไฟล์ | เนื้อหา |
|---|---|

### บอทบันทึกอะไรบ้าง

`bot.log` เก็บ **DEBUG ทั้งหมด** ส่วนหน้าจอเห็นแค่ INFO เวลามีปัญหาจะได้ย้อนดูได้ทีละรอบ
ไฟล์หมุนเมื่อโตถึง 5MB เก็บย้อนหลัง 5 ไฟล์ ไม่กินดิสก์ไม่จำกัด

ในไฟล์จะมี:

- ทุกรอบตรวจ 30 วินาที (แท่งล่าสุด ราคา spread ประมวลผลแล้วหรือยัง)
- ทุกแท่งที่ปิด พร้อม **เหตุผลครบทุกข้อ** ว่าตัวกรองไหนผ่าน/ไม่ผ่าน ด้วยตัวเลขอะไร
- สถานะไม้ที่ถืออยู่ทุกรอบ (ticket ราคาเข้า SL TP กำไร)
- ทุกครั้งที่ขยับ SL หรือเก็บกำไรบางส่วน
- ทุกคำสั่งที่ส่ง พร้อม retcode ถ้าไม่สำเร็จ
- ค่าคอนฟิกทั้งหมดตอนเริ่ม รวมทั้ง GMT offset ของ broker

### วิธีใช้ `market_training_data.csv` ให้คุ้ม

ตั้งค่าทั้งหมดอยู่เป็นค่าคงที่ตัวใหญ่ที่หัวไฟล์ `runner.py` (ตลาด ความเสี่ยง SL/TP),

- [ ] Tools → Options → Expert Advisors → ติ๊ก **Allow algorithmic trading**

- [ ] `.env` ถ้าอยากได้ Telegram (ไม่ใส่ก็รันได้)


## ข้อควรรู้

- **ยังไม่เคยทดสอบกับ MT5 จริง** โค้ดผ่านเทส logic แต่พฤติกรรมของ broker
  (retcode, ระยะ stop ขั้นต่ำ, filling mode) ต้องเจอของจริงถึงรู้ **รัน Demo ก่อน**
- บอทตัดสินใจจากแท่งที่**ปิดแล้ว**เท่านั้น จึงเข้าช้ากว่าแท่งปัจจุบันเสมอ — ตั้งใจให้เป็นแบบนั้น
  ไม่งั้นสัญญาณจะเปลี่ยนไปมากลางแท่ง
- MA crossover เป็นกลยุทธ์ตามเทรนด์ ในตลาด sideway จะแพ้เป็นชุด ตัวกรอง ADX
  ช่วยได้ระดับหนึ่ง แต่ไม่ได้แก้หมด
- การไล่ stop ทำให้ไม้ที่กำไรถูกปิดเร็วขึ้น กำไรต่อไม้จะลดลงแลกกับการรักษากำไรได้แน่นอนขึ้น
  ถ้าอยากปล่อยให้วิ่งยาว ให้เพิ่ม `TRAIL_ATR_MULT` หรือปิด `USE_TRAILING`
- ผลบน Demo ไม่เท่ากับผลจริง เพราะไม่มี slippage และการ requote แบบบัญชีจริง
